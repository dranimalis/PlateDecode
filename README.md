# 🇮🇩 PlateDecode

A simple Indonesian license plate decoder built with vanilla HTML, CSS, and JavaScript.

PlateDecode can identify:

- 📍 Registration region
- 🔢 Registration number
- 🔤 Series/suffix
- 🚗 Vehicle type

## ✨ Features

- Indonesian license plate decoding
- Automatic uppercase formatting
- Automatic plate formatting
- Vehicle type detection
- Regional detection
- Lightweight
- No backend
- No database
- No frameworks
